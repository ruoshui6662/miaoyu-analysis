# 妙舆 UI 设计规范与现状审查

> 日期：2026-09-04
> 状态：规范已开始落地，第一批 UI 优化已完成，待用户确认；本轮只改屏幕视觉，不改业务数据与接口。
> 适用范围：首页、分析、历史、设置四个面板、登录与安全提醒；网页桌面端和移动端。
> 本文用于下一轮设计与开发。与旧版视觉说明不一致的部分，作为待确认的新规范，不代表现有实现已达标。业务功能、API、来源 Logo 和报告数据口径不在本次变更范围。

## 1. 判断基准：以任务效率为核心，而不是模仿“大厂外观”

圆角、卡片本身不是错误，也不存在“大厂软件不能使用卡片”的统一规则。妙舆是需要反复阅读、检索和配置的分析工作台，评价标准应当是：用户能否迅速找到内容、识别状态、理解动作，并稳定完成任务。

当前的主要问题是：**边界多于必要分组，视觉强调多于重要动作，组件的外观又没有遵循相同规则。** 简单把所有圆角改小，或给所有控件统一涂白，都不能从根本上解决。

设计原则：

1. **边界必须有用途。** 标题、相邻关系和留白已经能说明归属时，不再增加背景、描边和阴影三重包裹。
2. **同级同形，不同级用语义区分。** 同一操作组的按钮同高、同字号、同圆角；用填充、描边和文字样式区分主次，不用忽大忽小表达重要性。
3. **颜色代表含义。** 可编辑、只读、禁用、选中、异常各有清晰状态；不能都用类似的灰底表达。
4. **移动适配不是等比放大。** 先重排内容、减少横向层级，再保证点击区域；不要把所有操作变成全宽红色按钮。
5. **内容比装饰重要。** 保留中文可读性、来源识别、明确时间和真实状态；不为“高级感”隐藏必要信息或降低对比度。
6. **规范必须能被验证。** 用浏览器实际计算尺寸、实际截图、键盘操作和窄屏检查验收，而不是仅检查 CSS 文件里是否出现某段规则。

## 3. 当前问题与修改意见

优先级：P1＝影响识别或操作的一致性问题；P2＝影响阅读效率、秩序与视觉质量的问题。以下优先级用于本项目排期，不表示已发生功能阻断。

| 优先级 | 当前证据 | 原因分析 | 建议 |
|---|---|---|---|
| P1 | 搜索设置测试按钮约 32px，保存按钮 52px；模型手机端“获取模型”36px，而操作组为44px | 尺寸分散在基础规则、页面规则、移动端规则中，同类动作缺少共同契约 | 建立常规、紧凑、触控三档；同组按钮严格同高 |
| P1 | 手机模型面板“测试连接”108×44、“删除服务商”121×44、“保存并启用”322×44 | 全局主按钮 `width:100%` 与页面规则叠加，使主动作变成单独的整行色带 | 删除通用全宽规则，按具体操作组排布；不足时换行，不挤压文字 |
| P1 | 顶栏“退出登录”在浅背景上接近白色 | 旧暗色顶栏文字样式未随浅色主题同步 | 按语义色设置普通、悬停、焦点状态；对比度单独验收 |

| P2 | 设置有白色外壳、灰色侧栏、灰色服务卡、灰色输入框，形成多层容器 | 导航、功能分组和表单控件都借助填充背景表达层级 | 去掉非必要外壳及内卡；导航用激活标记，服务组用标题与间距 |
| P2 | 分析“最近分析”仍表现为圆角白卡，而部分其他列表已经无框 | 多轮样式优先级不同，局部“无框”规则未真正覆盖当前 DOM | 先清点并合并规则，再验收真实节点计算样式，不再末尾连续补丁 |
| P2 | SearXNG 输入框只占部分宽度，配置徽标靠到更远的右侧 | 标签行与输入区域使用不同宽度上限，视觉归属不清 | 标签、状态、输入、帮助归入同一字段容器，并共享宽度 |
| P2 | 灰色输入框叠在近似灰色服务卡上，调用顺序静态值又像输入框 | 可编辑与只读没有分配独立的视觉语义 | 输入采用白底+明确细边；只读顺序采用文本，禁用才用弱灰底 |
| P2 | 历史列表每行都有醒目的红色“查看报告/查看进度”按钮 | 将高频行内动作误当作全页主动作 | 改为轻量文字动作或中性按钮；保留清晰的点击目标与悬停反馈 |
| P2 | 首页平台筛选为成排胶囊，焦点卡阴影、状态小胶囊同时出现 | 分组、筛选、状态使用相近的封闭外形，视觉噪声累积 | 平台导航改为下划线标签，静态状态减少底色，只保留必要的语义标记 |
| P2 | 手机模型面板存在较长的服务商列表、说明、大片区间和操作区 | 桌面布局直接堆叠为纵向，缺少移动任务优先级调整 | 缩短重复说明与区间；后续可评估紧凑服务商选择器，但需独立交互确认 |
| P2 | 图表、观点、报告外层均存在卡片式表达 | 文档阅读层级沿用控制台卡片样式 | 图表靠标题与图例组织；观点用引用排版，参考资料连续编号，打印单独设计 |

## 4. 视觉基础规范

### 4.1 容器与分组

默认优先顺序：**相邻关系 → 留白 → 标题 → 细分隔 → 背景面 → 描边 → 阴影**。前一种方式已经足够时，不叠加后一种。

| 元素用途 | 默认形态 | 不采用的方式 |
|---|---|---|
| 页面章节、普通功能分组 | 无背景、无外框，24–32px 组间距 | 每段都包圆角卡片 |
| 连续任务、来源列表 | 对齐的行、必要的水平分隔、行悬停 | 每行一个带阴影的独立小卡 |
| 表单控件 | 细描边、白底、6px 圆角 | 灰底套灰底；透明到无法识别边界 |
| 真正独立的工作面，如报告预览 | 可选单层中性工作面、0–8px 圆角 | 外卡+内卡+图表卡三重相套 |
| 提醒、错误、风险说明 | 小面积语义色及说明文字，4px 圆角 | 普通帮助信息全部使用彩色警告框 |
| 对话框、弹出菜单 | 8–12px 圆角，必要阴影 | 为去卡片化而取消浮层边界 |
| 开关、头像、品牌资产 | 依据原生语义或资产规范 | 强行把开关或 Logo 改为直角 |

普通页面不以“卡片数量越少越好”为目标；新增一个背景面时，设计者必须能说清它表示的独立任务或层级。

### 4.2 颜色语义与建议 Token

保留妙舆红色品牌与现有来源 Logo。以下为本轮已落地的浅色基线：冷白页面底、白色内容面、极弱结构分隔；不使用暖灰作为大面积背景。

| Token 角色 | 建议值 | 用途 |
|---|---|---|
| 页面背景 | `#F7F8FA` | 全局冷白画布，避免发黄 |
| 内容/输入背景 | `#FFFFFF` | 连续工作面、可编辑控件 |
| 次级表面 | `#FBFCFD` | 只读、辅助区和轻量悬停 |
| 次级表面强调 | `#F1F3F5` | 选中/悬停，不作为大面积容器底色 |
| 主要文字 | `#282D34` | 正文、控件内容 |
| 标题文字 | `#181C22` | 页面、模块标题 |
| 次要文字 | `#565E68` | 说明、字段辅助信息 |
| 辅助文字 | `#68717C` | 元信息，不继续降低到难读的浅灰 |
| 结构分隔 | `#EDF0F3` | 非交互分组细线 |
| 控件边界 | `#CBD3DC` | 输入框边界；聚焦时使用品牌色描边；不与极弱结构分隔混用 |
| 操作强调 | `#D93030` | 主动作、链接与选中标记；不修改品牌 Logo 原始色值 |
| 强调悬停 | `#BA2525` | 主动作悬停 |
| 强调浅底 | `#FFF2F1` | 小面积选中或反馈 |

约束：普通文字对比度目标至少 4.5:1；有意义的图标、焦点和控件边界目标至少 3:1。浅色分隔仅用于辅助结构，不能独自承担交互识别。错误要同时有文字，不依赖红色。深色模式必须有独立语义映射与实际验收，不直接反色。页面背景、输入背景、内容面必须从语义 Token 读取，禁止在页面组件内重新写暖灰色值。

### 4.3 字体与间距

- 沿用系统中文字体栈，不为此次调整增加在线字体下载。
- 桌面页面标题28px，移动26px；模块标题20–22px；子标题16px；正文与普通按钮14px；元信息12–13px。
- 正文行高1.6–1.75，控件文字保持单行且垂直居中；不缩小字体来容纳溢出。
- 移动端文本输入字号16px；重要提示不能塞进11px小字。
- 间距以4px为基准，优先8/12/16/24/32。相关字段组内16–24px，独立功能组间24–32px。
- 桌面主要内容宽度约1120–1200px，页面左右至少24px；手机左右16px，避免外卡、内卡继续吃掉有效宽度。
- 长文报告控制阅读行宽；热榜等结构化列表使用工作区宽度。不是所有页面都拉成同样的正文行宽。

## 5. 组件规范

### 5.1 按钮

| 类型 | 桌面 | 移动/触控 | 使用范围 |
|---|---|---|---|
| 常规操作 | 高40px，字号14px，左右14–16px | 高至少44px，字号14px，左右12–16px | 保存、测试、获取模型、编辑、导出 |
| 紧凑工具 | 高32–36px，字号12–13px | 热区至少44×44px，不沿用小热区 | 密集列表工具、分页、次级刷新 |
| 主研判入口 | 高44px | 高44px；文本放大时允许增高 | 首页及分析主题输入旁的开始按钮 |
| 图标按钮 | 图形16px，桌面热区32–40px | 图形仍16px，热区至少44×44px | 密钥可见性、移除、展开等 |

具体要求：

- 同一操作组使用同一尺寸档；“保存并启用”不得比旁边测试按钮高一截。
- 宽度按文案+内边距计算，不要求字数不同的按钮完全等宽。安全提醒这种对称二选一可等宽。
- 每个当前任务区一般最多一个实心主动作；重复列表行的查看、下载不使用满列表实心红块。
- 普通保存按钮不全宽。登录提交等明确的单一路径可以全宽，并以专用组件规则声明。
- 手机操作组空间不足时正常换行并保留间距，不把主按钮设成 `width:100%` 作为全局解决方案。
- 禁止通过 `width:0`、裁切、固定过小宽度把中文挤成竖排；长文案或大字体时允许组换行和按钮增高。
- 错误与删除使用危险语义，不能只靠“也是红色”区分。删除保留清晰文案及必要确认。
- 加载时按钮宽度稳定，提供“保存中”等文字并阻止重复提交；禁用态与加载态不能只改透明度而无行为限制。

### 5.2 输入、选择与只读信息

- 常规输入、选择框与相邻按钮同高：桌面40px，移动44px。多行文本框独立按内容设置。
- 标签、配置状态、输入框、帮助和错误属于一个字段容器，共享宽度与对齐基线。
- 可编辑：白底、细边、明确文本；悬停：边界变化；聚焦：清晰外轮廓；错误：边界+具体说明。
- 只读账号、固定调用顺序优先呈现为标签和值，不画成一个看似可编辑的灰色输入框。
- 占位符只作示例，不能替代持久可见的标签。API Key、模型名称、来源地址都需要可访问名称。
- 密钥显示按钮与输入框同高热区，图标居中；预留右侧空间，文字不被图标覆盖。
- 错误贴近字段，保留已填内容；保存状态使用状态区域，Toast 不作为唯一错误信息来源。

### 5.3 导航、列表与状态

- 顶部导航维持品牌+文字入口，下划线表达当前页面，不再叠一层胶囊导航底座。
- 设置桌面侧栏176–192px，用细分隔与激活标记表达位置；不得为了填满页面而设置高大的灰底侧栏。
- 设置手机端优先显示“搜索服务 / 分析模型 / 信息来源 / 账户管理”四个名称，必要时省略装饰性图标，不隐藏功能。
- 平台筛选使用下划线页签；能操作、有选中状态；与静态状态徽标的外观区分。
- 状态徽标保留文字：未配置、已配置、使用中、失败；静态状态不做成仿按钮。
- 来源行保留固定 Logo 槽位、名称、等级、开关；来源网址继续不直接展示，不能因此去掉可追溯信息入口。
- 固定图形尺寸：普通功能图标16px、紧凑装饰图标14px、品牌/来源标识按各自资产尺寸；不得将 Logo 与功能图标强行统一为同一图形面积。
- 图片与失败回退图标互斥显示；不修改此前已经修复的来源映射与图片比例。

## 6. 各页面的目标呈现

| 页面 | 内容结构 | 优化重点 | 保留能力 |
|---|---|---|---|
| 首页 | 主输入 → 当前焦点 → 刚刚发生 → 热榜 | 取消大面积浮起卡；焦点用标题与指标组织；平台改下划线标签 | 开始研判、热点入口、筛选、时间说明、原文跳转 |
| 分析 | 主题与参数 → 进度 → 报告 → 最近记录 | 输入控件与按钮对齐；进度和最近记录用连续区块；报告操作中性化 | 参数、阶段状态、重试、编辑及三格式导出 |
| 历史 | 检索筛选 → 主题列表 → 展开运行与导出 | 行内动作轻量化；筛选控件同高；详情只保留一层次级背景 | 搜索、状态/时间筛选、分页、各任务独立状态 |
| 搜索服务 | 服务配置 → 调度说明与策略 → 保存 | 服务分组去卡片化；字段状态对齐；只读顺序不仿输入 | 配置保存、密钥脱敏、连接测试、故障跳过说明 |
| 分析模型 | 服务商选择 → 当前表单 → 操作 → 默认服务商 | 收敛双侧栏的视觉重量；三个操作按钮同档；手机避免全宽保存条 | 新增/选择/删除、模型获取、测试、保存启用 |
| 信息来源 | 搜索/添加 → 来源分类列表 | 用小标题和行分隔；每类展开互不干扰；不靠空白等高填充 | 来源开关、等级、搜索、添加、展开 |
| 账户与提醒 | 状态说明 → 密码字段 → 保存 | 必要的安全提醒保留；普通帮助不用重复警告；弹窗按钮对齐 | 初始密码提醒、密码校验、保存与错误反馈 |
| 报告阅读 | 标题 → 图表 → 观点/正文 → 参考资料 | 减少图表与引用边框；正文行宽与字号先于装饰；引用有来源归属 | 图表、原文链接、编辑、导出、参考资料尾置 |

## 7. 移动端与无障碍验收要求

- 首轮覆盖360、390、430、768、1024、1440px；横屏和200%缩放另验收。视口宽度只是测试条件，不能等同于实机验证。
- 页面级不出现意外横向溢出；表格确有必要时使用明确的局部滚动，不能全局 `overflow-x:hidden` 掩盖内容。
- 分组在空间不足时由两列变一列；控件使用 `min-width:0` 允许收缩，URL 和长标题有明确换行策略。
- 44px是本项目触控区域下限，不要求图标扩大到44px，也不要求所有按钮充满一行。
- Tab、Shift+Tab、Enter、Space、Escape 按控件语义可用；焦点可见，不被固定栏裁掉；模态对话框需管理焦点并在关闭后返回触发位置。
- 输入支持密码管理器与粘贴；装饰图标不重复朗读，有意义的图标按钮有名称。
- 状态不能只依赖颜色；交互元素的边界和普通文字分别检查对比度。
- 支持减少动态效果偏好；加载和反馈不能通过动画成为唯一信息。
- 手机上的四项设置入口、报告操作、安全提醒均须真实点击验证；当前仅观察和测量，不宣称全部通过。
