# 妙舆项目交接说明

> 快照日期：2026-09-05 ｜ 适用分支：`main`

## 1. 先做什么

新成员按以下顺序建立上下文：

1. 阅读 [`docs/开发手册.md`](开发手册.md) 的 §3 当前进度、§4 待人工验证、§5 关键决策。
2. 查看最近提交：

   ```bash
   git log --oneline -5
   git status --short
   ```

3. 本机启动前端/后端，确认 `/healthz`；需要 PDF 时安装 Node 依赖和 Chromium。
4. 修改后先跑编译、单测和静态差异检查，再更新开发手册和里程碑日志。

## 2. 项目结构

| 目录/文件 | 作用 |
|---|---|
| `backend/app.py` | Flask API、认证、任务和导出接口 |
| `backend/pipeline.py` | 采集、AI 四章分析、报告数据编排 |
| `backend/search_providers.py` | SearXNG/Brave/Tavily 路由与故障切换 |
| `backend/hotlists.py` | 六个平台热榜采集、归一化和降级 |
| `docs/雷达功能规划与实施规范.md` | 已确认的雷达 UI、六层信源、数据/API 和 RADAR-1~5 验收基线 |
| `backend/scripts/gen_docx.mjs` | Word 报告生成 |
| `backend/scripts/render_pdf.mjs` | Playwright + Chromium PDF 原生打印 |
| `frontend/index.html` | 无构建单页应用、CSS token、页面交互 |
| `data/` | SQLite、任务素材、报告文件和运行时配置 |
| `.github/workflows/docker-publish.yml` | `main` 推送后构建并发布 GHCR 镜像 |

## 3. 本机开发

```bash
cd backend
pip install -r requirements.txt
cd scripts
npm install
npx playwright install chromium
cd ../..
cp .env.example .env
python backend/app.py --port 5000
```

Windows 若 Playwright 默认 headless-shell 启动失败，设置完整 Chrome 路径：

```powershell
$env:MIAOYU_CHROMIUM_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
python backend/app.py --port 5000
```

## 5. 发布与部署

推送 `main` 后，GitHub Actions 发布：

```text
ghcr.io/ruoshui6662/miaoyu-analysis:latest
```

NAS/FNOS 升级：

```bash
docker compose pull
docker compose up -d --force-recreate
docker compose ps
```

保留 `data` 挂载；不要执行 `docker compose down -v`。PDF 报错时先检查容器是否使用了新镜像，再检查：

```bash
docker compose exec yuqing node --version
docker compose exec yuqing sh -lc 'test -d /ms-playwright && node -e "require(\"playwright\"); console.log(\"playwright OK\")"'
```

## 6. 关键约束

- 首次网页登录账号为 `admin`，初始密码为 `password`；生产环境登录后必须在“设置 → 账户管理”修改。
- `MIAOYU_ADMIN_TOKEN`、AI Key、Brave/Tavily Key 不得提交 Git 或打进镜像；设置接口只返回掩码/配置状态。
- 搜索调用顺序固定为 SearXNG → Brave → Tavily；SearXNG 未配置时自动跳过，不阻塞已配置的后备服务。
- 前端无构建，修改 `frontend/index.html` 后刷新即可；若浏览器显示旧样式，先确认服务返回的是当前工作区并执行强制刷新。
- 真实人工验收未完成的项目保持 `✅`，只有按清单实际验证后才能标为 `✅✅`。
