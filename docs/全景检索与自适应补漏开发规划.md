# 妙舆 · 全景检索与自适应补漏开发规划

> 版本：v1.1 ｜ 日期：2026-09-05 ｜ 状态：`PANORAMA-1` 已实现待人工验收；查询扩展、覆盖补漏和付费墙处理尚未开发
>
> 适用范围：单次舆情分析的检索与证据编排。雷达仍按“结构化信源增量采集 + 本地关键词匹配”运行，不把本方案直接改造成高频轮询。

## 1. 问题定义

当前默认检索链路偏向中文和国内来源：查询语言、关键词模板和信源分组均以中文为主；默认 `failover` 又会在第一个服务返回非空结果后停止。因此“搜到了若干条”只证明接口可用，不证明信息覆盖完整。

需要解决的不是“多加几个海外网站”，而是以下四个可验证的问题：

1. 什么时候事件确实需要海外、官方或学术视角；
2. 首轮检索缺了什么，而不是机械地把所有 Provider 全部调用一遍；
3. 不同语言、地区和机构对同一事实是否相互独立；
4. 付费墙、登录墙和版权限制下，系统实际读到了什么、允许保存什么、报告能声称什么。

核心目标是：**先用低成本首轮检索建立事实骨架，再按覆盖缺口追加最少的查询；无法获取的证据明确标注，不绕过访问限制，也不由模型补写。**

## 2. 第一性原理与硬边界

### 2.1 第一性原理

- **结果数量不等于视角宽度**：同一通讯社被多家转载仍可能只有一个事实源。
- **海外不等于英文**：应按事件相关地区、机构和来源角色选取语言；日本、韩国、法国等事件不能只追加英语。
- **媒体不等于事实原点**：政策、制裁、监管、司法和公司事项应优先寻找发布该行为的机构原文。
- **发现不等于阅读**：搜索摘要只能证明页面存在，不能证明系统核验了完整正文。
- **可访问不等于可再利用**：`robots.txt`、站点条款、API 许可、版权和订阅授权是不同层级的约束。
- **缺失必须可见**：如果官方原文、独立媒体或专业意见没有获得，应在报告中显示覆盖缺口，不能让模型补成“完整观点”。
- **成本由增量收益约束**：只有新增查询可能补齐缺口时才继续；达到覆盖、预算或时间上限即停止。

### 2.2 绝对禁止

- 不绕过付费墙、登录、验证码、反爬、地区限制或访问频率限制；
- 不保存媒体账号密码、个人 Cookie、浏览器会话或订阅凭据；
- 不使用缓存站、盗版镜像、未授权转载站规避原站限制；
- 不因 `robots.txt` 允许抓取就推定允许保存、分析或商业再利用；
- 不把“仅标题/摘要可见”表述为“已阅读全文”；
- 不把海外媒体自动标记为客观，也不把国内来源自动降权；
- 不在普通分析默认开启所有 Provider 的全量并发；
- 不把本规划直接用于雷达高频轮询。

## 3. 总体架构

在现有 `SearchRouter` 上方增加检索编排层，保留 Provider 的故障隔离职责：

```text
用户主题
  ↓
ScopeClassifier（范围判定）
  ↓
QueryPlanner（实体别名、语言、来源角色查询族）
  ↓
SearchRouter（SearXNG → Keenable → Brave → Tavily）
  ↓
EvidenceNormalizer（来源、语言、时间、访问深度归一）
  ↓
CoverageEvaluator（覆盖缺口与独立性判断）
  ├─ 已达标 / 无边际收益 → 停止
  └─ 有明确缺口且预算允许 → AdaptiveSupplementer → 下一轮
  ↓
报告证据集 + 覆盖说明 + 补漏记录
```

`SearchRouter` 继续负责“哪个服务可用”；新增编排层负责“还缺哪类证据”。二者不得混为一个巨型搜索函数。

## 4. 检索范围判定

### 4.1 范围类型

| 类型 | 定义 | 默认处理 |
|---|---|---|
| `domestic` | 主要事实、决策者和影响范围均在国内，未发现明显跨境外溢 | 中文低成本首轮，不强制海外补漏 |
| `international` | 主体或事实核心发生在境外 | 按相关国家/机构语言执行全景检索 |
| `cross_border` | 国内事件涉及境外主体、供应链、外交、贸易、资本市场或国际传播 | 国内与相关境外证据并行覆盖 |
| `unknown` | 信息不足或信号冲突 | 先低成本首轮，再按结果实体和缺口二次判定 |

### 4.2 判定信号

强信号：境外国家/政府/监管机构/国际组织；战争、制裁、外交、跨境贸易、全球供应链；明确外文实体；用户指定海外视角。

中信号：跨国公司、海外上市、境外业务占比较高；首轮结果出现境外回应、跨国争议或显著外文实体；事件已被多个地区报道。

弱信号：纯本地公共服务、国内地方通报、无跨境影响的消费或社区事件。

### 4.3 判定方式

第一版采用**可解释规则 + 词典 + 实体别名**，不新增一次大模型调用，当前已在 `backend/panorama.py` 落地：

- `score >= 0.75`：直接进入全景检索；
- `0.40 <= score < 0.75`：先执行低成本首轮，由覆盖评估器决定是否补漏；
- `score < 0.40`：保持国内模式；
- 战争、制裁、外交、重大跨境安全等高影响主题将阈值下调；
- 阈值是初始工程参数，必须用标注集校准，不作为永久业务真理。

用户入口提供 `自动判断 / 仅国内 / 全景检索` 三态。手动选择高于自动判定，但系统仍记录原始判定分数和覆盖缺口。

## 5. 查询规划

### 5.1 实体与语言扩展

为每个核心实体建立查询别名：

- 中文全称、简称和旧称；
- 官方英文名、当地语言名、常见音译；
- 公司股票代码、产品名、机构缩写；
- 人名的本地书写和拉丁转写；
- 事件动作词：声明、调查、制裁、召回、裁决、回应、数据发布等。

禁止用通用机器翻译把整句复制成十种语言。只为与事件相关的语言生成短查询，避免噪声和额度浪费。

### 5.2 查询族

| 查询族 | 目标 | 示例约束 |
|---|---|---|
| `fact_cn` | 国内事实骨架 | 中文关键词 + 时间窗 |
| `primary_official` | 事实原点 | 相关政府、监管、法院、公司、国际组织官方域名 |
| `media_international` | 境外独立报道 | 相关地区语言 + 专业媒体来源池 |
| `expert_academic` | 专业解释与历史背景 | 大学、智库、研究机构、OpenAlex/Crossref 元数据 |
| `public_response` | 公众/社区反应 | 仅在任务确实需要时启用，不作为事实依据 |

来源池是“发现范围”，不是白名单裁决。任何来源仍按原始证据、独立性和访问深度评分。

## 6. 覆盖评估与自适应补漏

### 6.1 覆盖维度

每条证据至少记录：

- `source_language`：实际内容语言；
- `source_region`：来源机构所在地区及事件相关地区；
- `source_role`：`official/media/academic/expert/community/company`；
- `independence_group`：通讯社、稿源或同一集团归并标识；
- `access_status`：系统实际访问深度；
- `published_at/acquired_at`：发布时间和发现时间；
- `query_variant`、`search_pass_id`：由哪轮哪条查询得到。

### 6.2 最低覆盖目标

仅对 `international/cross_border` 强制评估：

1. 至少一个与核心事实直接相关的官方/第一方来源；
2. 至少一个与第一方独立的专业媒体来源；
3. 事件涉及技术、法律、金融、医疗等专业判断时，至少一个学术/专业机构来源；
4. 至少覆盖事件核心地区的一种主要语言；
5. 同一稿源的转载不计为多源交叉验证。

如果公开网络不存在某类材料，结果应为“未获取”，而不是验收失败或虚构内容。系统输出缺口和原因。

### 6.3 补漏触发器

- `missing_primary_source`：只有媒体转述，没有官方/第一方原文；
- `single_independence_group`：多条结果实为同一稿源；
- `language_gap`：只有中文二手转述，没有相关地区语言材料；
- `region_gap`：来源全部来自同一地区；
- `role_gap`：只有媒体，没有专业/官方来源；
- `metadata_only_critical`：关键论据只来自付费墙标题或摘要；
- `freshness_gap`：事件持续发展，但结果集中在过早时间点。

### 6.4 停止条件与预算

默认参数建议：

- 每个缺口最多追加 2 条查询；
- 每个任务最多 6 条补漏查询、最多 2 轮；
- 同一 Provider 单轮空结果不重复提交等价查询；
- 普通模式相对当前基线最多增加 30 秒软预算；全景模式最多增加 90 秒软预算；
- 连续一轮新增独立来源为 0 时停止；
- 达到覆盖目标、用户取消、额度阈值或全局时间上限立即停止。

用户实测 Keenable 单独生成约 80 秒，只记录为当前环境的性能快照，不作为 SLA。后续以 P50/P95 和查询数回归衡量。

## 7. 最低成本的信息获取顺序

“最低成本”同时包括费用、延迟、稳定性、法律风险和维护成本：

1. **第一方公开材料**：政府、监管、法院、国际组织、公司新闻稿、RSS/Atom；免费且可追溯性最高。
2. **SearXNG 多语言定向检索**：使用语言、时间和站点约束发现公开网页；边际请求成本低。
3. **Keenable**：作为第一外部补漏，利用较高免费额度和双时间字段；仍须真实质量与许可验收。
4. **开放学术元数据**：OpenAlex/Crossref 用于发现论文、作者、机构、DOI 和开放获取位置，不把元数据当论文正文。
5. **Brave Search API**：使用独立索引扩大公开网页覆盖。
6. **Tavily**：仅在重点任务、前序缺口仍存在时使用；默认关闭答案和全文返回以控制成本与来源失真。
7. **商业内容 API/数据库**：只有业务明确需要且许可允许分析、保存和商业使用时接入。

Provider 顺序不是永恒固定的质量排名。编排器应按查询族选择 Provider；例如官方域名定向查询优先 SearXNG/Keenable，开放论文查询优先 OpenAlex/Crossref，不能让所有查询族共用一个全局顺序。

## 8. 海外媒体付费墙处理规范

### 8.1 核心判断

付费墙问题不能用“能不能抓下来”定义，而要拆成四问：

1. 能否发现该文章；
2. 系统实际能读取到哪一层；
3. 获取方式是否获授权；
4. 许可是否允许当前用途、保存时长和商业化使用。

### 8.2 访问状态机

| `access_status` | 系统实际获得内容 | 可用于什么 | 报告标记 |
|---|---|---|---|
| `open_fulltext` | 无需登录即可访问的公开正文，且抓取规则允许 | 可抽取事实、引用有限片段、生成摘要 | 已核验公开正文 |
| `licensed_api` | 通过已授权 API 获得的正文/字段 | 严格按套餐和许可使用、保存 | 已通过授权 API 核验 |
| `metadata_only` | 标题、媒体、URL、日期和合规摘要/snippet | 只用于发现、线索和覆盖说明 | 仅标题/摘要可见，正文未核验 |
| `user_supplied` | 用户自行粘贴或上传其有权使用的材料 | 仅在当前工作区处理，记录用户提供来源 | 用户提供材料，授权范围待用户确认 |
| `blocked` | 登录墙、付费墙、验证码、robots 禁止或地区限制 | 不抓正文；寻找公开第一方或合法替代来源 | 访问受限 |
| `unknown` | 网络/解析异常，无法确认访问层级 | 不进入高置信事实 | 获取状态未知 |

另设 `content_rights`：`public / api_permitted / user_provided / restricted / unknown`。访问状态与使用权必须分开存储；页面公开可读也不自动等于可批量归档或用于商业训练。

### 8.3 处理流程

```text
发现付费媒体链接
  ↓
仅记录搜索服务合法返回的标题/URL/时间/摘要
  ↓
检查公开可访问性、robots 与来源许可
  ├─ 公开且允许 → 抽取公开正文，记录读取深度
  ├─ 已有合法 API 授权 → 按合同字段与保存期限读取
  ├─ 用户提供材料 → 工作区内处理并记录来源
  └─ 受限/未知 → 不绕过，转而寻找：
        ① 官方原文 ② 作者/机构公开版本 ③ 合法通讯社转载
        ④ 开放获取论文/预印本 ⑤ 另一家独立公开报道
```

寻找替代来源不是寻找盗版副本。合法替代必须有自身发布权或明确开放许可。

### 8.4 报告降级规则

- 关键事实只有 `metadata_only`：不得写成确定事实，必须标注“该媒体标题/摘要显示……，正文未核验”。
- 多家媒体都复述同一付费报道：仍计一个 `independence_group`。
- 找到官方原文：以官方原文核验事实，付费媒体可作为 framing/关注角度线索。
- 找到另一家独立公开报道：可以形成交叉验证，但不得声称验证了付费文章的全文内容。
- 找不到合法替代：保留引用卡和覆盖缺口，不让 AI 依据标题扩写细节。
- 任何报告的“参考资料”都要显示媒体名、标题、日期、URL 和访问标签。

### 8.5 产品形态与凭据边界

MVP 不提供媒体订阅登录。后续如商业客户确有授权数据库：

- 只接官方 API 或企业内容许可，不接浏览器 Cookie；
- Key 放服务端密钥库，按工作区隔离，不回传浏览器；
- 接入前登记用途、允许字段、速率、保存期限、删除义务和是否可用于 AI 分析；
- 自部署用户自行提供 Key 时仍需显示许可提示，系统不能暗示“买了个人订阅即可自动抓取”；
- SaaS 对外收费前必须由运营/法务确认内容许可，免费开发者 Key 不得直接用于商业服务。

例如 Guardian Open Platform 的开发者访问面向非商业用途；商业企业以及生成式 AI、文本/数据挖掘、情感分析等用途需要商业访问。该差异说明“API 可申请”并不等于“商业舆情产品可免费使用”。

## 9. 数据模型与接口契约

### 9.1 证据字段

在现有 Mention/搜索结果上增量加入：

```text
source_language
source_region
source_role
independence_group
access_status
content_rights
retrieval_method
verified_depth
query_variant
search_pass_id
coverage_tags[]
```

`verified_depth` 可取 `metadata/snippet/partial/full`。AI 只接收与其任务相符的内容层级，禁止把 `metadata` 混入“已阅读全文”的证据池。

### 9.2 检索计划与覆盖快照

第一版优先在任务 JSON 中保存，稳定后再拆表：

```json
{
  "scope_decision": {
    "mode": "cross_border",
    "confidence": 0.82,
    "reasons": ["foreign_regulator", "multinational_entity"]
  },
  "search_passes": [],
  "coverage_summary": {
    "languages": ["zh", "en"],
    "regions": ["CN", "US"],
    "roles": ["official", "media"],
    "missing": ["expert_academic"]
  },
  "supplement_log": []
}
```

后续需要跨任务质量分析时再增加 `search_plans`、`search_passes`、`coverage_snapshots` 表，避免规划阶段先做重迁移。

### 9.3 API

- `POST /api/analyze` 增加可选 `search_scope=auto|domestic|panorama`；缺省为 `auto`；
- 任务状态返回 `scope_decision`、当前检索轮次和剩余预算；
- 报告 JSON 返回 `coverage_summary` 和 `supplement_log`；
- 设置项只提供管理员可见的默认预算、允许的 Provider 和来源许可配置；
- 不新增端口，不新增独立服务，不改变现有 Provider Key 的脱敏规则。

## 10. UI 与报告呈现

分析输入区只增加一个紧凑范围选择器，默认“自动判断”。运行后显示一行可解释状态，例如：

> 已识别为跨境事件：涉及美国监管机构；正在补充英文官方来源与独立媒体。

报告头部增加“证据覆盖”摘要，不新增大圆角卡片：

- 语言：中文、英语；
- 地区：中国、美国；
- 来源角色：官方 2、媒体 6、研究机构 1；
- 独立稿源：5；
- 访问受限：2（仅标题/摘要）；
- 缺口：未找到公开的当事方完整回应。

参考资料条目使用轻量标签：`公开正文`、`授权 API`、`仅摘要`、`用户提供`、`访问受限`。标签必须描述访问事实，不评价媒体立场。

## 11. 失败、性能与可观测性

- Provider、语言查询和来源抓取分别记录成功/空结果/限流/授权错误/解析失败；
- `401/403` 不自动重试；`402` 标记额度耗尽；`429` 冷却；网络/5xx 按现有策略回退；
- `robots.txt` 因网络或 5xx 不可达时按完全禁止处理；成功读取后遵守匹配规则并设置不超过 24 小时的常规缓存；
- 记录每轮查询数、独立来源增量、覆盖增量、Provider 延迟和估算成本；
- 普通国内任务的 P50 延迟相对现有基线回归不超过 10%；全景任务单独统计，不与普通任务混算；
- 补漏失败不应让整个报告失败，必须输出已有证据和明确缺口。

## 12. 分期开发计划

## 13. 验收清单

### 13.1 范围判定

- [ ] 建立不少于 60 个标注主题，四类各有代表样本和边界样本；
- [ ] 明确国内事件在自动模式不触发海外补漏；
- [ ] 外交、制裁、跨境监管、国际供应链等强信号可稳定触发；
- [ ] 用户可手动覆盖，任务记录自动判定与手动值。

### 13.2 覆盖与成本

- [ ] 同一通讯社多次转载只算一个独立稿源；
- [ ] 补漏只针对缺失维度，最多 2 轮/6 条查询；
- [ ] 连续无新增独立来源时停止；
- [ ] 未配置 Provider 自动跳过，已配置 Provider 单点失败不阻断；
- [ ] 普通模式 P50 回归不超过 10%，全景模式有独立 P50/P95。

### 13.3 付费墙与版权

- [ ] 不保存个人 Cookie、媒体账号和订阅凭据；
- [ ] 登录墙/验证码/robots 禁止时不抓正文；
- [ ] `metadata_only` 不进入“已阅读全文”的事实池；
- [ ] 关键事实仅有摘要时，报告强制显示“正文未核验”；
- [ ] 授权 API 配置包含用途、字段、配额、保存期限和商业使用状态；
- [ ] 用户提供内容与公开内容分开标记并可按工作区清理；
- [ ] 导出的 PDF/Word/Markdown 都保留访问标签和覆盖缺口。
